# Bella Doll Nails — Landing Page

Landing page για το στούντιο νυχιών **bella_doll_nails** (Πάτρα).
Instagram: https://www.instagram.com/bella_doll_nails/

Ενιαίο `index.html`, χωρίς εξαρτήσεις, στα ελληνικά, σε σκούρο στυλ με ροζ-χρυσές αποχρώσεις (ίδια παλέτα με το olgas.nailsss).

## Ενότητες

1. Hero
2. Υπηρεσίες και τιμές
3. Gallery φωτογραφιών
4. Πώς δουλεύει (3 βήματα)
5. Φόρμα κράτησης
6. FAQ
7. Footer

## Πώς συμπληρώνεις τα στοιχεία

Όλα τα στοιχεία που αλλάζουν βρίσκονται στο block `CONFIG` στην αρχή του `<script>` μέσα στο `index.html`:

- **Υπηρεσίες**: όνομα, τιμή, διάρκεια. Όσα μένουν κενά εμφανίζονται ως "—".
- **Ώρες λειτουργίας**: ανά ημέρα. Κενά = "—".
- **Gallery**: λίστα με αρχεία φωτογραφιών από τον φάκελο `images/`.

## Gallery

Μέχρι να μπουν φωτογραφίες, το gallery δείχνει placeholders. Για να βάλεις δικές σου:

1. Φτιάξε φάκελο `images/` δίπλα στο `index.html`.
2. Ανέβασε εκεί τις φωτογραφίες (π.χ. `nails-1.jpg`).
3. Πρόσθεσε τα ονόματα των αρχείων στο `CONFIG.gallery`.

## Φόρμα κράτησης

Η φόρμα δεν στέλνει δεδομένα σε server. Συντάσσει το μήνυμα κράτησης, το **αντιγράφει στο πρόχειρο** και ανοίγει το **Instagram DM**
(https://ig.me/m/bella_doll_nails), ώστε ο πελάτης να κάνει επικόλληση και αποστολή.

## Δημοσίευση

Είναι στατικό αρχείο. Μπορεί να δημοσιευτεί με GitHub Pages (Settings → Pages → Branch `main`, φάκελος `/ (root)`) ή σε οποιοδήποτε static hosting.
